Timeline QA Tool

Bookmarklet-loadable normalized realtime-feed simulator for manual Timeline testing.

Open timeline-qa-tool.js

Load the script in the sportsbook page's main context. The tool only injects normalized realtime records; it does not render or force a Timeline tab.

Before loading the page, use a DevTools Local Override for config.json to set incidentsTimeline.enabled to the boolean true. The tool's Expose action reloads with the two exposed-state query parameters; restart the bookmarklet manually afterwards.
